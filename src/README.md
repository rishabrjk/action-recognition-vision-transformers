# Source Code

This folder is reserved for reusable source code from the action recognition pipeline.

Planned source modules:

- `data_loader.py` — dataset loading and frame sampling utilities
- `train.py` — model training and fine-tuning script
- `evaluate.py` — classification and localisation evaluation
- `models.py` — model wrappers for TimeSFormer, VideoMAE, and ViViT
- `localisation.py` — localisation decoder experiments

The current repository is structured as a portfolio version of the academic project. Code will be added as it is cleaned and documented.
