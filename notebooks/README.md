# Notebooks

This folder is reserved for the project notebooks used for video action recognition experiments.

Planned notebook structure:

- `01_data_preprocessing.ipynb` — loading frame sequences, preparing HMDB_simp and JHMDB splits
- `02_model_comparison.ipynb` — comparing TimeSFormer, VideoMAE, and ViViT
- `03_ablation_studies.ipynb` — testing temporal sampling, fine-tuning depth, augmentation, and learning rate schedules
- `04_localisation_experiments.ipynb` — evaluating localisation decoders on JHMDB

The full experimental workflow is summarised in the main `README.md`.
