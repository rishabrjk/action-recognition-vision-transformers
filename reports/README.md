# Reports

This folder is reserved for project reports, summaries, and experiment documentation.

The project evaluated transformer-based video models for action recognition and localisation, including:

- TimeSFormer
- VideoMAE
- ViViT
- Cross-attention localisation decoder
- DETR-style localisation decoder

Key reported results:

- Best model: VideoMAE with partial fine-tuning
- Top-1 accuracy: 93.62%
- Top-5 accuracy: 98.40%
- Macro F1: 0.9332
- Best localisation decoder: Cross-attention
- Frame-mAP: 60.40%
- Video-mAP: 58.36%

The main findings are summarised in the root `README.md`.
